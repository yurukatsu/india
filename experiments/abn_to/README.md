# 異常回転率（abn_to）の検証

`market_basics/04_stock_timeseries` で既存特性を制御しても残った「異常回転率」（当月の回転率 / 過去 12 か月平均）を、既存の素材と同じ規約で評価する。

- スコア生成: `scripts/build_abn_to.py` → `input/msci_india_imi/alpha/abn_to/{abn_to,abn_to_med,abn_to_q}/`
- 中立化版: `build_neutralize.py` → `alpha/abn_to_neu/abn_to_neu`（log 時価総額・mom1・mom12_1・tover・vola60・skew60・セクター）
- 複合: `build_blend.py` → `alpha/composite/comp_ew_{90,80,70}_abnto_{10,20,30}`、`comp_ew_{..}_abntoneu_{..}`
- 評価: `01_abn_to.ipynb`（コマンドはノートブック冒頭）

## 結論

**`comp_ew` と独立した本物の情報だが、ロングオンリー・税控除後の上乗せは確認できない。素材としての採用は見送り。**

| | IC（t） | Q5−Q1 | 税控除後 Q5 EW 超過 | 回転率 |
| --- | --- | --- | --- | --- |
| `comp_ew` | 0.065（7.0） | 17.6% | 8.5% | 4.0 |
| `abn_to` | 0.016（2.5） | 4.1% | −0.4% | 7.5 |
| `abn_to_med` | 0.022（3.4、OOS 1.9） | 8.8% | 1.9% | 6.5 |
| `abn_to_neu` | 0.017（4.0、IS 3.4 / OOS 2.8） | 4.7% | −0.2% | 7.2 |
| `comp_ew` 80 : `abn_to` 20 | 0.066（7.2） | 18.3% | 8.2% | 4.3 |

- 差の多くは Q1 側（小型株で出来高が細った銘柄が翌月負ける）。大型・中型ではほぼ効かない。
- 効きは 1〜2 か月（k = 2 まで有意）で、後で反転はしない。
- `comp_ew` との順位相関 −0.02、残差 IC t 2.6〜3.5、スパニング α t 2.1〜3.4。リビジョンや決算の言い換えではない。
- `comp_ew` の Q5 から `abn_to_med` の下位 20% を外すと、税控除前 +0.15%/月（t 3.5）、税控除後 +0.07%/月（t 1.5）。新規に入る銘柄だけ外す形で +0.04%/月（t 1.6、回転率は増えない）。

残すなら bax の新規買いのタイブレーク程度。詳細と次の候補はノートブックの所見を参照。
