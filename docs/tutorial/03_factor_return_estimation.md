# 第3章: ファクターリターン推定（クロスセクション回帰）

マルチファクターモデルの基本形と、ファクターリターンの推定を整理する。ここでの時制の要点はただ一つ:

$$r_{i,t \to t+1} = \sum_{k} x_{i,k,t} \, f_{k,t \to t+1} + u_{i,t \to t+1}$$

**エクスポージャー $x_{i,k,t}$ は期初（時点 $t$、$\mathcal{F}_t$ で確定）、ファクターリターン $f_{k,t\to t+1}$ とスペシフィックリターン $u_{i,t\to t+1}$ は期中 $(t, t+1]$ に実現する。** 左辺と右辺の $x$ の時点がズレた瞬間にルックアヘッドになる。

## 3.1 モデルの構成要素

行列表記（時点 $t$ のユニバース $N_t$ 銘柄、$K$ ファクター）:

$$\mathbf{r}_{t \to t+1} = X_t \, \mathbf{f}_{t \to t+1} + \mathbf{u}_{t \to t+1}$$

- $X_t \in \mathbb{R}^{N_t \times K}$: エクスポージャー行列（第2章の出力。業種・国ダミー、市場切片を含む場合あり）
- $\mathbf{f}_{t \to t+1} \in \mathbb{R}^{K}$: ファクターリターン（推定対象）
- $\mathbf{u}_{t \to t+1}$: スペシフィックリターン

慣例として $\mathbf{r}$ には超過リターン $r^e$（対無リスク）を使う。

## 3.2 クロスセクション回帰（各期）

各期 $t$ ごとに独立に回帰する:

$$\hat{\mathbf{f}}_{t \to t+1} = (X_t^\top W_t X_t)^{-1} X_t^\top W_t \, \mathbf{r}_{t \to t+1}$$

- **OLS**: $W_t = I$
- **WLS（Barra流）**: $W_t = \text{diag}(\sqrt{\text{MktCap}_{i,t}})$ 等。小型株のスペシフィックリターン分散が大きいことへの対処（不均一分散対応）。ウェイトも**時点 $t$ の時価総額**を使う
- 業種ダミー＋市場切片を同時に入れる場合は多重共線性が生じるため、制約付き回帰（例: 業種ファクターリターンの時価総額加重和 = 0）で識別する

### タイミング上の注意

- 回帰は「期初の $X_t$」に「期中のリターン」を写像するもの。$X_{t+1}$（期末のエクスポージャー）で回帰すると、リターンの結果（価格変動でB/Pが動く等）を説明変数に使うことになり典型的なルックアヘッド
- ユニバースは $\mathcal{U}_t$（期初時点）。期中の上場廃止銘柄も含める（第1章1.3のデリスティングリターンを $\mathbf{r}$ に入れる）

## 3.3 ファクターリターンの解釈: ファクターポートフォリオ

推定式を書き換えると:

$$\hat{f}_{k,t \to t+1} = \sum_i \omega^{(k)}_{i,t} \, r_{i,t \to t+1}, \qquad \Omega_t \equiv (X_t^\top W_t X_t)^{-1} X_t^\top W_t$$

つまり各ファクターリターンは**ウェイト $\omega^{(k)}_{i,t}$（$\Omega_t$ の第 $k$ 行）を持つロング・ショートポートフォリオのリターン**。このポートフォリオは:

- ファクター $k$ へのエクスポージャーが 1
- 他のファクター $j \ne k$ へのエクスポージャーが 0（**純粋ファクターポートフォリオ**）

という性質を持つ（$\Omega_t X_t = I$ より）。ウェイト $\omega^{(k)}_{i,t}$ は $\mathcal{F}_t$ のみで構成されるため、$\hat{f}_{k}$ は**実際に組成可能な戦略のリターン**として解釈できる（取引コスト・空売り制約を除く）。単変量ソート（分位LS）との違いは、他ファクターを直交化した「純粋な」効果である点。

## 3.4 時系列統計量とプレミアムの推定（Fama-MacBeth）

各期の $\hat{f}_{k,t \to t+1}$ を時系列に並べ:

$$\bar{f}_k = \frac{1}{T} \sum_{t} \hat{f}_{k,t \to t+1}, \qquad \text{se}(\bar{f}_k) = \frac{\hat{\sigma}(f_k)}{\sqrt{T}}, \qquad t\text{値} = \frac{\bar{f}_k}{\text{se}(\bar{f}_k)}$$

### Fama-MacBethの2段階構造と標準誤差

手続きを分解すると:

1. **第1段階（各期のクロスセクション回帰）**: 3.2の $\hat{\mathbf{f}}_{t \to t+1}$ を全 $t$ について計算 → ファクターリターンの時系列 $\{\hat{f}_{k,t \to t+1}\}_{t=1}^{T}$ を得る
2. **第2段階（時系列平均の検定）**: 上式の $\bar{f}_k$ と $\text{se}(\bar{f}_k)$ を計算し、$H_0: E[f_k] = 0$ を検定

この構成の要点は、**リターンのクロスセクション相関（同一期の銘柄間相関）を標準誤差の計算で明示的にモデル化しなくてよい**こと。銘柄間の相関はすべて各期の $\hat{f}_{k,t \to t+1}$ という1個のスカラーに集約され、第2段階は「$T$ 個の時系列標本の平均の検定」に還元される。パネル回帰を素朴にプールしてOLS標準誤差を使うと銘柄間相関で標準誤差が過小評価されるが、Fama-MacBethはこの問題を構造的に回避している。

ただし第2段階の素朴な標準誤差 $\hat{\sigma}(f_k)/\sqrt{T}$ が正しいのは **$\hat{f}_{k,t \to t+1}$ が時系列方向に無相関**の場合のみ。自己相関があると分散の見積もりが誤る（正の自己相関なら過小評価 → $t$ 値の過大評価）。

### Newey-West修正

自己相関・不均一分散に頑健な長期分散（HAC分散）で置き換える:

$$\widehat{\text{Var}}_{\text{NW}}(\bar{f}_k) = \frac{1}{T} \left[ \hat{\gamma}_0 + 2 \sum_{j=1}^{L} \Big(1 - \frac{j}{L+1}\Big) \hat{\gamma}_j \right], \qquad \hat{\gamma}_j = \frac{1}{T} \sum_{t=j+1}^{T} (\hat{f}_{k,t} - \bar{f}_k)(\hat{f}_{k,t-j} - \bar{f}_k)$$

- $\hat{\gamma}_j$: ラグ $j$ の標本自己共分散。Bartlettカーネル $(1 - j/(L+1))$ で重み付けして足し込むことで、分散推定の正定値性を保ちながらラグ $L$ までの自己相関を取り込む
- ラグ次数の目安: $L = \lfloor 4(T/100)^{2/9} \rfloor$（Newey-Westの自動選択）や $L \approx T^{1/3}$。月次20年（$T=240$）なら $L = 4 \sim 6$ 程度
- $t$ 値は $\bar{f}_k / \sqrt{\widehat{\text{Var}}_{\text{NW}}(\bar{f}_k)}$ に置き換わる

### 自己相関が生じる典型原因（実務）

| 原因 | 内容 |
|---|---|
| **オーバーラップ・リターン** | 月次時点で「先3ヶ月リターン」等を被説明変数にすると、隣接する観測が2ヶ月分重複し機械的にMA型自己相関が生じる。この場合はラグを重複期間以上（$L \ge 2$）に取るのが必須。可能なら非オーバーラップ設計が先決 |
| ファクター自体の持続性 | モメンタム系ファクターリターンは自己相関を持ちやすい |
| ボラティリティ・クラスタリング | 2次の依存（GARCH的）。平均の検定にはNewey-Westで概ね対応可 |

### 補足: Fama-MacBethの限界

- **EIV（変数誤差）問題**: 本来のFama-MacBeth（ベータを第1段階で推定→第2段階でベータに回帰）では推定ベータの誤差が第2段階のバイアスになる。本章の設定（エクスポージャー $X_t$ が観測可能な特性値）ではこの問題は生じない
- Newey-Westは自己相関の**存在自体**は直さない。自己相関が強い場合、そもそも $E[f_k]$ が一定という前提（レジーム変化・ファクター減衰）を疑うほうが実務的には重要
- **研究モードと運用モードの区別**:
  - 全期間の $\bar{f}_k$ を眺めて「効くファクター」を選ぶ → その後同じ期間でバックテスト、は**選択バイアス**（データスヌーピング）。全期間統計は事後検証・診断用
  - 運用でファクター選択・ウェイトを動かすなら、時点 $t$ での判断は $\{\hat{f}_{k,t' \to t'+1}\}_{t' < t}$ のみに基づく（第2章2.6と同じ規律）

## 3.5 スペシフィックリターンとスペシフィックリスク

$$\hat{u}_{i,t \to t+1} = r_{i,t \to t+1} - \mathbf{x}_{i,t}^\top \hat{\mathbf{f}}_{t \to t+1}$$

銘柄選択アルファの実現値は主に $u$ に現れる（ファクター中立戦略の場合）。第7章の要因分解で使う。

### スペシフィックリスクの推定

時点 $t$ のスペシフィックリスク $\hat{\sigma}_{u,i,t}$ は、残差の時系列 $\{\hat{u}_{i,s}\}_{s \le t}$ から推定する。大原則は第0章と同じ — **推定ウィンドウは $t$ で閉じる**。

#### (a) EWMA（指数加重移動平均）

$$\hat{\sigma}^{\text{TS}\,2}_{u,i,t} = (1 - \lambda) \sum_{j=0}^{J} \lambda^{j} \, \hat{u}^2_{i,t-j}, \qquad \lambda = 2^{-1/h}$$

（肩添字TSは時系列（Time-Series）推定値の意。(c) の構造モデル推定値 $\hat{\sigma}^{\text{struct}}$ と区別するため）

- $h$: 半減期（half-life）。**日次残差なら $h = 42 \sim 90$ 営業日**が商用モデルの典型（リスクの応答性と安定性のトレードオフ。予測ホライズンが長いほど $h$ も長く）
- 残差の平均は理論上ゼロに近いため demean せず二乗をそのまま使うのが実務的
- 単純ローリング標準偏差（等ウェイト、窓 $L$）は $\lambda \to 1$ の特殊ケース。窓の端で古い観測が突然抜ける「ゴースト効果」があるためEWMAが好まれる

#### (b) 頻度変換と年率化

日次で推定して月次・年次ホライズンに変換する場合:

$$\hat{\sigma}^{\text{ann}}_{u,i,t} = \hat{\sigma}^{\text{TS,daily}}_{u,i,t} \times \sqrt{252}$$

- $\sqrt{252}$ ルールは日次残差が無相関の場合のみ正確。スペシフィックリターンには**非同期取引・ビッドアスクバウンス由来の自己相関**が残ることがあり（特に低流動性銘柄）、その場合はNewey-West型の調整（自己共分散項を加えたスケーリング）を入れる
- リバランスが月次でも**リスク推定は日次残差ベース**が標準（月次だと観測数が足りない: 5年でも60点）

#### (c) 構造モデルとのブレンド（履歴不足・外れ値対策）

時系列推定が使えない・不安定な銘柄（新規上場、履歴の短い銘柄、TOB等のイベント銘柄）への対処として、スペシフィックリスクを銘柄特性で説明する**構造モデル**を併用する:

$$\log \hat{\sigma}^{\text{struct}}_{u,i,t} = \mathbf{b}_t^\top \mathbf{c}_{i,t} + e_{i,t}$$

- $\mathbf{c}_{i,t}$: 時点 $t$ の銘柄特性（サイズ、業種、ボラティリティ・エクスポージャー等 — すべて $\mathcal{F}_t$）
- $\mathbf{b}_t$ は時点 $t$ のクロスセクション回帰で推定（履歴が十分な銘柄で推定し、不足銘柄に外挿）
- 最終推定値はブレンド: $\hat{\sigma}_{u,i,t} = \phi_{i,t} \, \hat{\sigma}^{\text{TS}}_{u,i,t} + (1 - \phi_{i,t}) \, \hat{\sigma}^{\text{struct}}_{u,i,t}$。$\phi_{i,t} \in [0,1]$ は履歴の長さ・データ品質に応じたウェイト（Barra型モデルの標準的な設計）

#### (d) ベイズ縮小

時系列推定のノイズ（少数銘柄の極端な推定値）をクロスセクション平均に向けて縮小する:

$$\hat{\sigma}^{\text{shrunk}}_{u,i,t} = \nu_{i,t} \, \bar{\sigma}_{g(i),t} + (1 - \nu_{i,t}) \, \hat{\sigma}^{\text{TS}}_{u,i,t}$$

- $\bar{\sigma}_{g(i),t}$: 同一グループ（サイズ分位×業種等）の平均スペシフィックリスク（時点 $t$ のクロスセクション）
- **縮小強度 $\nu_{i,t} \in [0,1]$ は「定数を直接指定」ではなく「データ依存の関数形＋チューニング定数」で設計する**のが標準。代表的な2流儀:

  1. **Barra型（乖離度ベース）**:
     $$\nu_{i,t} = \frac{q \, |\hat{\sigma}^{\text{TS}}_{u,i,t} - \bar{\sigma}_{g(i),t}|}{\Delta_{g(i),t} + q \, |\hat{\sigma}^{\text{TS}}_{u,i,t} - \bar{\sigma}_{g(i),t}|}$$
     $\Delta_{g,t}$ は群内推定値のクロスセクション標準偏差。群平均からの乖離が大きい（＝ノイズか外れ値の疑いが強い）推定値ほど自動的に強く縮小される。こちらが指定するのはチューニング定数 $q$ のみ（バイアス統計量等の事後診断で調整）

  2. **経験ベイズ型（精度加重）**:
     $$\nu_{i,t} = \frac{s^2_{i,t}}{s^2_{i,t} + \tau^2_{g,t}}$$
     $s^2_{i,t}$: 時系列推定値の推定誤差分散（履歴が短いほど大）、$\tau^2_{g,t}$: 群内の真のリスクのばらつき。履歴の短い銘柄ほど群平均に強く寄る、というベイズ更新そのものの形

- いずれも縮小の効果は、リスクの過小推定銘柄への過大なウェイト配分（最適化での「エラー・マキシマイゼーション」）の抑制。$\nu$ の関数形とチューニング定数の決定は**モデル設計時に固定し、バックテスト期間内の結果を見て遡って調整しない**（それ自体がインサンプル最適化）

#### PITチェック

1. EWMA・ローリング窓は $t$ で閉じているか（バックテストループ内で全期間の残差系列を先に作ってから `std()` を取っていないか — 実装上の典型ミス）
2. 構造モデル・縮小のクロスセクション統計は時点 $t$ のものか
3. 残差 $\hat{u}_{i,s}$ 自体が「当時のモデル $X_s, \hat{\mathbf{f}}_s$」から計算されているか（現在のファクター定義で過去の残差を再計算するのは、モデル改定の影響評価としては有用だが、当時実現できた運用の再現ではない）

## 3.6 推定上の実務論点

| 論点 | 内容 |
|---|---|
| 頻度 | 推定頻度（月次/日次）はリバランス頻度と独立に選べる。リスク推定用には日次、プレミアム評価には月次が典型 |
| ユニバース整合 | 推定ユニバース＝投資ユニバースが基本。推定だけ広いユニバースで行う場合、ファクターリターンの意味が変わることに注意 |
| 外れ値 | スペシフィックリターンの外れ値（TOB等）が $\hat{f}$ を歪める。ロバスト回帰またはイベント銘柄の除外規約 |
| 共線性 | 相関の高いファクター同士（バリュー系複数等）は $\hat{f}$ が不安定化。第2章の合成でまとめるか、リッジ等で正則化 |

## 3.7 チェックリスト

1. 回帰の説明変数は $X_t$（期初）、被説明変数は $r_{t \to t+1}$（期中）— 時点は非重複か
2. WLSのウェイト・ユニバースも時点 $t$ のものか
3. 期中の上場廃止銘柄を回帰から落としていないか
4. ファクター選択・動的ウェイトの判断に全期間の $\bar{f}_k$ を使っていないか（研究モードと運用モードの混同）
5. スペシフィックリスクの推定ウィンドウは $t$ 以前で閉じているか
