# comp_ew の市場頑健性

`comp_ew` がどんな市場環境・サブユニバース・時期で効かなくなるかを、ロングオンリーの指標（Q5 − BM、Q5 − ユニバース EW）を中心に横断的に確認する。

- 評価: `01_market_robustness.ipynb`
- 状態変数: `scripts/market_states.py`（`market_basics/03` の定義を関数化。月末に確定する状態と、同じ月の状態）
- 共有データ: `data/market_panel/`（`scripts/build_market_panel.py`）

## 結論

**選択力（Q5 − EW）は時期にはきわめて頑健（19 年すべてプラス）だが、効いているのは小型株の中だけで、市場環境では「リスクオンの急反発」に弱い。**

| 弱点 | 中身 | 根拠 |
| --- | --- | --- |
| BM 比の負け | サイズの構造的な賭け。シグナルの問題ではない | 大型優位・狭い相場の月は Q5−BM −22〜−25% だが Q5−EW は +12〜+16% |
| シグナルの負け | 弱気相場からの反発、モメンタムの崩れ、バリュー相場、INR 高（FPI 流入） | 反発月（15 か月）は Q5−EW −29%（t −4.7）。選択はモメンタム +0.27・バリュー −0.11（R² 0.70） |
| 大型・中型で効かない | BM ユニバース（大型 + 中型）内の IC は IS 0.062 → OOS 0.007。3 スリーブとも 2018 年以降ほぼ 0 | 小型の中は IC 0.075（OOS 0.067）で頑健 |

- 月末に分かる状態では、前月末の高ボラ・高相関・深いドローダウンの翌月に弱い（IC の差 t −3.0〜−3.2）。`market_basics/03`・`05` の「ストレス時にアクティブリスクを縮める」と整合する。
- セクターには頑健（11 中 10 で IC 正。エネルギーだけ効かない）。
