# 5. 主要な発見・注意点・次のステップ

## 5.1 主要な発見

1. **リビジョンとモメンタムがインドの主力**。core rev3 系（L/S +16%）・alt rev_gdb（Q5 +7〜8%、
   raw/中立とも有意）・mom12 系。3つの物差し（分位・IC・ファクターリターン）すべてで整合
2. **AI スコアは大型ユニバースで最良のロングオンリー特性**（Q5 IR 1.05、単調、超過DD −6%）。
   ただし短命（IC は h=3 で消滅）・高回転・カバレッジは実質ベンチ銘柄のみ
3. **中立化（size+sector）はスクリーニングの必須工程**:
   - 効果が強まる: mom12 / mom12_1 / rdp / TVL / esg_s_composite（中立化で有意化）
   - 剥落する: マージン系（ois_est 等）— 素の Q5 超過はセクター配分だった
   - ファクター選定は**中立化版を正**とするのが安全
4. **バリューのロング側は死んでいる**（B/P 非単調・Flow Value の効果は全てショート側）。
   例外は配当系（dp_act / dp_est / rdp）
5. **EW→CW で崩れる = 中小型偏重**はモメンタムで顕著（2017年以降に乖離拡大）。
   AI は逆に大型で成立する数少ないシグナル → 住み分けが合成上好都合
6. 独立性: AI・rev_gdb・TVL・コアの相互相関はほぼゼロ → 分散効果が期待できる

## 5.2 注意点（結果を引用する際に必ず添える）

- **多重検定**: 100+37 本をスキャンして NW t ≥ 2 で拾っている。偶然でも片側 ~5% は超えるため、
  単発の t 2.0〜2.5（rdp, dp_est, esg_* 等）は「候補」であって「結論」ではない。
  リビジョン/モメンタム/AI のように**複数の物差し・複数のバリアントで同時に立つもの**を優先する
- **期間の非対称**: alt/AI は 2013〜/2016〜年開始でコア（2007〜）より短く、強気相場に偏る
- **幾何 vs 算術**: 棒は幾何年率。高ボラ分位はドラッグで沈む（t 値は算術側の検定）
- **タイの多い離散ファクター**（コントラバーシー等）は分位が擬似乱数的に割れる → IC を読む
- **TVL 型の「分位○/IC×」**は非単調・非定常のサイン。時系列を必ず確認
- コストは未控除。回転率（AI 443%、rev1 系 17回転/年）を掛け合わせて判断する
- 中立化 × CW は「シグナル評価」ではなく「キャパシティ検査」。
  大型での有効性検定は**ベンチ銘柄限定 EW**の方が素直（未実施 → 次ステップ）

## 5.2.5 棄却済みのアイデア（再検証しない）

- **税制調整 CGO（LIO/RO/TLO 3成分分解、notebooks/12）**: 単変量では効いて見えるが
  すべてモメンタム/CGO の言い換え。Fama-MacBeth（cgo_60m + mom12_1 + mom1 コントロール）で
  全成分 |t| < 1。h = 21/42/63 でも同じ。レジーム単調性（LIO が pre-2018 で最強）と
  TLO の 1-2月マイナス→3月プラスの季節性のみ示唆的だったが、深掘りせず棄却（2026-09 決定）

- **H-Q3 反トンネリング交差（Prof × Payout、notebooks/13）**: 事前固定した主検定
  （srtn への FM、交差項、採択ライン NW t > 2.5）で t = 0.62。頑健性 2×2 でも |t| < 0.9、
  IS/OOS で符号反転（+1.0 / −0.7）。二重ソートでは**逆方向**（Payout スプレッドは
  低 Prof 群で +6.1%/年 t 2.5、高 Prof 群で +2.1% t 0.8、差の差は負）。
  「高収益×低還元のディスカウント」は不在。**Payout の主効果は生存**
  （doe: rtn t 3.7 / srtn t 2.3）→ 交差ではなく単体でクオリティ合成へ（2026-09 決定）

- **H-Q5 成長調整クオリティ（Prof × Asset Growth、notebooks/14）**: 交差項 t = −0.50
  （符号も予測と逆）。**分割推計で高収益群でも `ta_grw` 係数は負のまま**
  （High: t −3.1 / Low: t −2.7、srtn）— 符号反転は不在。二重ソートでも Growth スプレッドは
  全 Prof 段で負（−4.5〜−7.7%/年）、最良セルは「高収益×**低**投資」(+6.9%) で米国型そのもの。
  gpa×ppe_grw 交差はむしろ有意に負（t −2.2）。**インドでも資産成長は無条件に負** —
  P6 の懸念（成長経済では投資の符号が違う）は否定。acc_bs 正アノマリーの説明にもならず、
  同パズルは未解決のまま残る。副産物: `ta_grw` 主効果は srtn でも t −3.4 と頑健な負
  （BARRA 控除後も残る）→ 単体でクオリティ側（負符号）に採用可（2026-09 決定）
