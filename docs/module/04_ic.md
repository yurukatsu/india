# fl.ic — Information Coefficient

## information_coefficient — 月次 IC の時系列

```python
ic = fl.ic.information_coefficient(
    panel,
    score_col="mom12_1_blom",  # スコア列
    ret_col="fwd_rtn",         # リターン列
    method="spearman",         # "spearman"（既定・タイに頑健）| "pearson"
    min_obs=20,                # 有効ペアがこの数未満の月は NaN
)
# -> Series（index=yyyymm）
```

**必要な列**: `score_col`, `ret_col`。
Spearman は単調変換で不変（raw / Blom で同一）。離散データのタイも平均順位で正しく処理される。

## ic_summary

```python
fl.ic.ic_summary(ic)
# n_months / mean_IC / std_IC / ICIR / ICIR_ann(×√12) / t_stat / t_stat_NW / hit_ratio / autocorr_1
```

有意性は `t_stat_NW`（IC 系列の自己相関を補正）で見る。

## ic_decay — ホライズン別 IC（h ヶ月先の単月リターン）

```python
panel = fl.data.add_forward_returns(panel, range(1, 13))   # ← 事前に必要
ic_ts, decay = fl.ic.ic_decay(panel, "mom12_1_blom", horizons=range(1, 13))
# ic_ts: 月次 IC（列 = h） / decay: h ごとの ic_summary（index=horizon）
```

**必要な列**: `fwd_rtn_1` ... `fwd_rtn_12`（`add_forward_returns` で付与）。
単月リターンなのでホライズン間の区間重複はない。
