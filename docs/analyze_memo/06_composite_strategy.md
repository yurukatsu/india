## 6.2 データとタイミング規約

- ユニバース: MSCI India IMI（`universe/{t}.pkl` の size ∈ {1,2,3}、毎月再構築）
- ベンチマーク: MSCI India（size ∈ {1,2}）。EW 評価はベンチ等W、CW 評価はベンチ時価総額W

## 6.4 スコアリング・パイプライン（毎月 t のクロスセクションで完結）

```
各素材 x について:
 1. Blom 正規スコア:  z_i = Φ⁻¹((rank_i − 3/8)/(n + 1/4))   同順位は平均順位
 2. 中立化: z を目的変数に [GICS上2桁 11セクターダミー | log(浮動株調整時価総額USD) | 定数]
    へ回帰（np.linalg.lstsq、毎月）、残差を SD=1 に再スケール → x_ss
    ※ cgo_gain は「正の銘柄のみ」の部分集合内で同じ処理
 3. 符号調整: 表6.3 の符号を掛ける

スリーブスコア（k ∈ {A, B, D}）:
 4. sleeve_k = mean(構成素材の x_ss, skipna)     ← 欠損素材は除いて平均（再ウェイト）
 5. sleeve_k を再 Blom（クロスセクション）

合成:
 6. comp_ew = mean(sleeve_A, sleeve_B, sleeve_D, skipna) を再 Blom
    ※ B の損側銘柄は cgo_gain が NaN → B は mom12_1 のみで構成される（設計仕様）
```

実装: `fl.multi.build_scores` 相当の `standardize_panel(..., group_col="sector",
control_cols=["log_cap"], suffix="_ss")` + skipna 平均 + 再 Blom（nb15 セル参照）。

## 6.5 分位・評価規約

- 5分位、**Q5 = スコア最上位**。分位割当は一様順位 u=(r−0.5)/n の等分割（昇順・降順で鏡像）
- EW: 分位内等W vs ベンチ等W / CW: 時価総額W vs ベンチ時価総額W
- 表示は幾何年率超過（`ann_excess`）、t は月次超過（算術）の Newey-West
- 回転率は期中ドリフト調整済み片道
- IC は月次 Spearman

## 6.6 ウェイト比較の3案（定義）

1. **comp_ew（本命）**: 上記2段等ウェイト
2. comp_flat: 12素材フラット等W（符号調整後、skipna）→ 再Blom
3. comp_icir: スリーブ間を過去 ICIR で加重。**PIT**: 時点 t のウェイトは
   「t 時点で実現済みの月次 IC（= t−1 月まで）」の expanding 平均/SD。最低36ヶ月未満は等W、
   負の ICIR は 0 にクリップして正規化。銘柄レベルでは利用可能スリーブのみで再正規化
