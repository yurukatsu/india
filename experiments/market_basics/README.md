# インド株市場の基礎分析（構造 × 時系列 × クロスセクション）

ファクター作りから一歩引いて、MSCI India IMI（プロキシ）の市場そのものを定量的に押さえ、時系列の情報をクロスセクショナルな運用に組み込む入口を探す。

- 共有データ: `scripts/build_market_panel.py` → `data/market_panel/`（git 管理外。初回のみ `uv run python scripts/build_market_panel.py`、1 分程度）
  - 日次: 終値・始値・高値・安値（分割調整済み、配当なし）、売買代金（INR）、回転率、日次リターン、オーバーナイト / 日中リターン
  - 月次: 時価総額、`drtn`（配当込み）、サイズ区分、GICS セクター、PBR / PER / 配当利回り
  - 指数: 時価総額加重（IMI、MSCI India プロキシ、大中小、セクター 11）と等ウェイト。日次は価格、月次は配当込み
- 規約: 月末 $t$ のユニバース → 月 $t+1$ の構成。主サンプル 2008-01〜2026-07。t 値は Newey–West。IS = 2008〜2017、OOS = 2018〜。

| ノートブック | 内容 |
| --- | --- |
| `01_structure_returns.ipynb` | 銘柄数・集中度・セクター・流動性の推移、指数の成績、サイズサイクル、分布、個別株の歪み（Bessembinder）、新規組み入れ銘柄 |
| `02_index_timeseries.ipynb` | 指数の自己相関・分散比、時系列モメンタム、ボラ（HAR・ボラ管理）、季節性（月替わり・F&O 満期・4 月・ムフラート）、オーバーナイト / 日中、為替 |
| `03_state_variables.ipynb` | 横断面の状態変数（分散・平均相関・ブレス・サイズサイクル・流動性・バリュエーション）による市場とファクターの条件付き成績 |
| `04_stock_timeseries.ipynb` | 銘柄リターンのラグ構造、Lo–MacKinlay 分解、リードラグ（大型 → 小型、業種 → 銘柄）、価格遅延、オーバーナイト / 日中の綱引き、異常回転率・MAX・52 週高値 |
| `05_factor_timeseries.ipynb` | core 123 本 + `comp_ew` のロングショートの時系列: 自己相関、ファクターモメンタム、ボラ・タイミング、価値スプレッド、市場との非対称 |

## 横断的な結論

**時系列の情報は「方向（いつ市場やファクターが上がるか）」には使えず、「量（いつアクティブの賭けを小さくするか）」と「日取り（いつ・どの順で売買するか）」に使える。**

### 1. 市場の方向は読めない（02・03・01）

- 指数の時系列モメンタムは無い（12 か月の符号 CW t −0.8、2018 年以降はむしろ反転）。セクターの TSMOM も t ≤ 1.5。
- バリュエーション・IPO 活動・流動性などの状態変数は、サンプル外 R² がほぼすべて負（過去平均に勝てない）。
- 指数のボラ管理はシャープ 0.50 → 0.61 だがアルファ t 1.5（OOS 0.6）。為替（INR 安）の予測力は IS だけ。
- サイズサイクル（EW − CW）は暦年 ±15〜30% の波を持つが、自己相関は |ρ| ≤ 0.11 で自分の過去からは読めない。

### 2. `comp_ew` の効き具合は読める → アクティブリスクの量を動かす（03・05、独立に同じ結論）

- `comp_ew` の Q5−Q1 は「コールの売り」型: 上昇月のベータ −0.70（t −9.8）、下落月 −0.17。弱気後の反発月（15 か月）は月 −6.9%（他の月 +2.1%）。
- ストレス状態（高ボラ・高い平均相関・高い横断面分散・低いブレス）の翌月は `comp_ew` が効かない。`avg_corr` 低 1.95% / 高 −0.84%（t −3.2）、`breadth_200` 低 −0.33% / 高 2.25%（t 2.8）。
  IC への回帰は IS・OOS とも同符号（`rv63` −2.3 / −5.4、`hl52` 2.6 / 3.6）。危機の月（2008-08〜2009-11、2020）を除いても残る。ロングオンリー代理（Q5 − EW ユニバース）でも同じ。
- 量を動かすだけの単純なルールで、両期間ともシャープが上がる:

  | ルール（パラメータ探索なし） | `comp_ew` Q5−Q1 のシャープ | 出典 |
  | --- | --- | --- |
  | 静的 | 1.27（2011〜）/ 1.35（2010-02〜） | 03 / 05 |
  | 市場ボラでスケール（$\overline{rv63}/rv63$、上限 2） | 1.46（IS 1.39 / OOS 1.66） | 03 |
  | ブレスが低い三分位で半分 | 1.47（IS 1.54 / OOS 1.45） | 03 |
  | `comp_ew` 自身の日次 L/S の実現分散でスケール（[0.5, 2]） | 1.57（アルファ t 3.4、IS 1.58 / OOS 1.55、Q5−EW でも 1.62 → 1.75） | 05 |

- 一方、中身（スリーブ・スタイルの配分）を過去の成績や割安度で動かす根拠は無い。ファクターモメンタムは銘柄モメンタム + 静的プレミアムで説明でき（切片 t −0.2）、
  価値スプレッドはモメンタム系以外で効かない。`style_dtw`・`momentum_regime` の否定的な結果と整合する。
  `momentum_regime` が効かなかったのは「モメンタムだけを外す」「24 か月リターンで判定」だったためで、負けているのは `comp_ew` 全体、判定は直近のボラ・相関・ブレスの方が早い。

### 3. 短い時間軸では「業種は続伸、銘柄は反転」（04・02、`industry_factor` と整合）

- 週次 FM: 同じセクターの他銘柄の前週リターン 1σ あたり翌週 +10.7bp（t 6.8、IS 4.1 / OOS 5.7）、自分の前週リターンは −8.4bp（t −3.4）。
  月次版は OOS で弱まる（t 1.9）ので、効果は週次に移っている可能性がある。
- 小型株は日次で続伸（t 7.2、値幅制限・非同時取引）、大型株は週次で反転（t −5.0）。EW・小型指数の日次自己相関 0.15〜0.19（t 7.7〜9.2）は 2018 年以降も残る。
- 大型 → 小型のリードラグ（Lo–MacKinlay の古典的結果）はインドでは出ない（日次 t 1.1）。

### 4. 新しい銘柄特性の候補（04）

- **異常回転率 `abn_to`**（当月の回転率 / 過去 12 か月平均）: mom1・mom12_1・tover・vola60・skew60・log 時価総額を制御して t 3.3（IS 2.5 / OOS 2.0、srtn t 3.7）。core の `tover` は水準なので重複が小さい。
- **オーバーナイト / 日中の綱引き**: 当月のオーバーナイトが高い銘柄は翌月もオーバーナイトが高く（t 16.0）、日中で負ける（t −11.2）。総リターンでは打ち消し合う（t 0.4）ので、アルファより執行の情報。
  指数でも CW のオーバーナイト年 +35.7%、日中 −25.1%（始値は板寄せ、終値は最後の 30 分の VWAP である点に注意）。
- 効かなかったもの: 価格遅延 D1（t 0.3）、MAX（−0.6）、52 週高値（1.1）、同月季節性（Heston–Sadka、1.1）。

### 5. カレンダー（02）

- 月替わり 4 日（全日数の 19%）で CW の累積の 93%。EW − CW は +10.9bp/日（t 5.2、IS 4.6 / OOS 2.6）。月初の SIP 資金と整合。
- 4 月: EW − CW +2.05%（t 3.9）、過去 12 か月の負け組 − 勝ち組 +2.78%（t 2.4、19 年中 12 年が正）。会計年度末（3 月）の節税売りの反動と整合。
- F&O 満期翌日 CW +27bp（t 2.8、OOS は弱い）、ムフラート取引日 EW − CW +0.50%（18 年すべて正）。

### 6. 市場構造は 2020 年以降に変わった（01・04・05）

- 銘柄数 249 → 622、上位 10 銘柄ウェイト（IMI）44% → 28%、小型株の売買代金の中央値は 4〜5 倍、Amihud の小型 / 大型の比は 72 倍 → 17 倍。
- 個別株は正の歪みが強い。生涯で指数に勝つのは 37%、正味の富の創出は上位 7%（75 銘柄）で全部。「狭い相場」（指数に勝つ銘柄が 3 割前後: 2008、2018、2019、2025）は等ウェイト Q5 の構造的な負けの年と重なる。
- 相対強度モメンタムは小型株の現象（Lo–MacKinlay の補正後、大型 + 中型ではほぼ 0）。
- ファクター間の第 1 主成分（収益性・クオリティ 対 割安）の説明力は 0.5 → 0.35、`comp_ew` と市場の相関は −0.77 → −0.25 に弱まった。

| --- | --- | --- | --- | --- |
| 1 | **`comp_ew` のアクティブリスクを状態で動かす**（自身の L/S の実現分散、市場ボラ・平均相関・ブレス） | 強い（03・05 が独立に到達、IS/OOS・危機除外・Q5−EW で残る） | 低い（`momentum_regime` は中身を外す二値判定で失敗） | bax の TE 目標 / リスク回避度を連続的にスケール。税・回転率込みで静的 TE と比較 |

| 3 | **ストレス時だけリスク中立化**（BETA・RESVOL・LIQUIDTY・SIZE の上限を絞る） | 中（ストレス × 上昇月の負けが原因） | 中（`momentum_regime` の含意を具体化） | bax の制約を状態依存にする |
| 4 | **4 月の節税売り反動**（3 月末にモメンタムを軽く / 会計年度の負け組を売らない） | 中（OOS は弱め） | 低い | `comp_ew`・`sleeve_b` を暦月で分解し、3 月末だけ重みを変える版を評価。自身の損出し（STCL）との組み合わせは税制を確認 |
| 5 | **リバランス日・執行の最適化**（月替わり・満期翌日の位置、銘柄別に始値 / 終値のどちらで出すか） | 中〜強（カレンダーと綱引きは強い） | 低い | 同じシグナルでリバランス日を ±5 営業日ずらす感度分析、約定価格の仮定を変えたバックテスト |

## 注意

- 多重検定: 各ノートで数十〜150 の検定を並べている。上の候補は「事前の仮説がある」「IS・OOS で同符号」「|t| ≥ 2.5 程度」を目安に選んだ。状態変数は 3 群（ストレス・ブレス・水準）に強く相関しており、独立な発見の数は見かけより少ない。
- ロングショートは等ウェイト・コスト控除前。アクティブリスクのスケーリングの実際の回転率・税（縮めた月の売却で STCG が出る）は未評価。
- オーバーナイトリターンの 3〜10% はちょうど 0（始値 = 前日終値、近年ほど多い）。累積の水準は割り引いて読む。
- 時価総額 `cap` の単位は 2007 年以前とそれ以降で異なる（2007-12 以降は USD 百万と推定）。月内のウェイトとして使う分には影響しない。
