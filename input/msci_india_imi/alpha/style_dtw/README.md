# スタイル類似局面（DTW）スコア

`scripts/build_style_dtw.py` で生成。日次スタイルリターン（スタイルスコアの Q5−Q1、等ウェイト）の直近 63 営業日の推移を過去と DTW で照合し、近傍 3 個の翌 21 日リターン平均でスタイルリターンを予測。予測 × スタイルスコアの和を各月ユニバース内で Blom 化。定式化と符号表は `experiments/style_dtw/README.md`。

| スコア | 定義 | 期間 |
| --- | --- | --- |
| `sdtw` | DTW 近傍 3 個の翌 21 日リターン平均 / σ̂（本命） | 201101〜202606 |
| `sdtw_z` | 窓ごとに標準化した形で DTW 照合 / σ̂ | 201101〜202606 |
| `sdtw_sign` | DTW 予測の符号のみ | 201101〜202606 |
| `sdtw_pos` | DTW 予測の正の部分のみ / σ̂ | 201101〜202606 |
| `sknn_euc` | ユークリッド距離の kNN（DTW との比較用）/ σ̂ | 201101〜202606 |
| `base_ew` | 全スタイル等ウェイト（静的） | 201101〜202606 |
| `base_hist` | 過去の平均リターン（拡大窓）/ σ̂ | 201101〜202606 |
| `base_mom12` | スタイルの 12 か月（252 日）モメンタム / σ̂ | 201101〜202606 |
| `base_mom3` | スタイルの 3 か月（63 日）モメンタム / σ̂ | 201101〜202606 |
