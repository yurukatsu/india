# 第7章: 評価（分位分析・要因分解・パフォーマンス計測）

シグナル（研究段階）と戦略（構築後）の評価を分けて整理する。評価はほぼすべて事後分析だが、**評価結果を運用判断にフィードバックする瞬間にPIT規律の対象になる**（研究モードと運用モードの区別、第3章3.4）。

## 7.1 分位ポートフォリオ分析（シグナル評価の標準）

### 基本形

各時点 $t$ で、スコア $z_{i,t}$ の順位でユニバースを $Q$ 分位（quintile: $Q=5$、decile: $Q=10$）に分割し、各分位のリターンを計算:

$$r^{(q)}_{t \to t+1} = \sum_{i \in \mathcal{Q}_{q,t}} w^{(q)}_{i,t} \, r_{i,t \to t+1}, \qquad q = 1, \dots, Q$$

- **分位の割当は時点 $t$ のスコア**、リターンは $(t, t+1]$ — 第0章の大原則の分位版
- 見るもの: (i) 分位間の**単調性**（トップからボトムへリターンが単調に並ぶか）、(ii) ロング・ショートスプレッド $r^{(1)} - r^{(Q)}$ の平均・t値（Newey-West、第3章3.4）、(iii) スプレッドがトップ側とボトム側どちらから来るか（ロングオンリー実装ならトップ側の超過が重要 — ボトム側だけ効くシグナルはショートできないと使えない）

### ウェイト規約の影響

- **等ウェイト**: シグナル評価の標準だが、暗黙に小型株を過大評価する（等ウェイトリバランス自体が小型・リバーサルプレミアムを含む）。等ウェイト分位で有効に見えたシグナルが時価総額ウェイトで消えるなら、実体は小型株効果の可能性
- **時価総額ウェイト**: 実運用への近似としてはこちらも併記するのが健全
- 分位内の銘柄数が少ないと（狭いユニバース × 細かい分位）、分位リターンがスペシフィックリスクに支配されノイジーになる。$N/Q \gtrsim 30$ 銘柄程度を目安に分位数を選ぶ

### カントリー中立・業種中立の分位分析

グローバル・新興国ユニバースでは、素朴な分位分割が**国・業種の集中**を生む（例: バリュー上位分位が特定国に偏る）。中立化の2方式:

**方式A: グループ内分位（sort within group）**

各国（各業種）$g$ の中で独立に分位分割し、同一分位を国横断で束ねる:

$$\mathcal{Q}_{q,t} = \bigcup_g \mathcal{Q}^{(g)}_{q,t}, \qquad \mathcal{Q}^{(g)}_{q,t}: \text{グループ } g \text{ 内でのスコア分位}$$

各分位の国・業種構成が自動的にユニバースと揃う。グループ内銘柄数が少ないと分位が粗くなるのが弱点。

**方式B: 中立化スコアで分位（第2章2.5の利用）**

国・業種を中立化したスコア $x_{i,k,t}$（回帰残差）でユニバース全体を分位分割。グループ内銘柄数の制約を受けにくいが、構成の中立性は近似的。

- どちらも「シグナルの効果」と「国・業種配分の効果」を分離する目的は同じ。**中立化仕様はIC評価（第4章4.1）と揃える**
- 分位内のウェイトも国中立にするか（国ごとにベンチマーク国ウェイトを維持）は追加の設計選択

## 7.2 パフォーマンス指標

区間 $(t, t+1]$ のアクティブリターン系列 $\{r^A_{t \to t+1}\}$ から:

$$\text{IR} = \frac{\bar{r}^A}{\hat{\sigma}(r^A)} \times \sqrt{P}, \qquad P: \text{年率化係数（月次なら12）}$$

- **IR（情報レシオ）**: アクティブリターン平均 ÷ 実現TE。第4章4.4の基本法則が予測しようとしていた量の実現値
- シャープレシオは超過リターン（対無リスク）版。アクティブ戦略の主指標はIR
- その他: 最大ドローダウン、ヒットレシオ（勝ち月比率）、スキュー（テイルの非対称性 — ショート側の裸のリスクがある戦略は要確認）
- **コスト控除前後を必ず併記**: グロスIRとネットIR（第6章6.3のコスト控除後）の差が「実装コスト」の総額

### 実現TEと予測TEの突合

$$\text{実現TE} = \hat{\sigma}(r^A) \times \sqrt{P} \quad \text{vs} \quad \text{予測TE} = \sqrt{\mathbf{w}^{A\top}_t \hat{V}_t \mathbf{w}^A_t}$$

系統的な乖離（実現 > 予測が続く等）はリスクモデルのバイアス（第5章5.4のバイアス統計量）か、リスクモデル外のベット（モデルにないファクターへのエクスポージャー）を示唆する。

## 7.3 要因分解（アトリビューション）

### ファクターベース分解

実現アクティブリターンをリスクモデルの構造で分解:

$$r^A_{t \to t+1} = \underbrace{\mathbf{b}^{A\top}_t \, \hat{\mathbf{f}}_{t \to t+1}}_{\text{ファクター寄与}} + \underbrace{\sum_i w^A_{i,t} \, \hat{u}_{i,t \to t+1}}_{\text{銘柄選択（スペシフィック）寄与}}$$

- **エクスポージャーは期初 $\mathbf{b}^A_t$、ファクターリターン・残差は期中** — 分解にも第0章の大原則がそのまま適用される。期末エクスポージャーで分解すると期中リターンの結果を原因側に混ぜることになる
- ファクター中立戦略なら、ファクター寄与 ≈ 0・スペシフィック寄与が主となるはずで、そうなっていなければ設計と実装の乖離（第6章のTC・制約の副作用）を疑う
- 各ファクター寄与 $b^A_{k,t} \hat{f}_{k,t \to t+1}$ の時系列累積で「意図したティルトが報われたか／意図しないティルトが損益を出したか」を監視

### Brinson型分解（配分 vs 選択）— 各バージョン

グループ（業種・国）$g$ ごとの伝統的分解。記法: $w^P_g, w^B_g$ はグループウェイト（**期初**）、$r^P_g, r^B_g$ はグループ内リターン（**期中**）、$r^B = \sum_g w^B_g r^B_g$。バージョンによって「配分効果」の定義と交差項の扱いが異なる。

#### (1) BHB（Brinson-Hood-Beebower, 1986）— 3項分解

$$r^A = \underbrace{\sum_g (w^P_g - w^B_g) \, r^B_g}_{\text{配分}} + \underbrace{\sum_g w^B_g \, (r^P_g - r^B_g)}_{\text{選択}} + \underbrace{\sum_g (w^P_g - w^B_g)(r^P_g - r^B_g)}_{\text{交差項}}$$

- 配分効果が**グループリターンの絶対水準 $r^B_g$** に掛かる。市場全体が上昇していると、ベンチマークに劣後するグループでもオーバーウェイトすれば配分効果がプラスに出る — この性質が直観に反するとして実務では次のBFが好まれる

#### (2) BF（Brinson-Fachler, 1985）— 3項分解

$$r^A = \underbrace{\sum_g (w^P_g - w^B_g)(r^B_g - r^B)}_{\text{配分}} + \underbrace{\sum_g w^B_g \, (r^P_g - r^B_g)}_{\text{選択}} + \underbrace{\sum_g (w^P_g - w^B_g)(r^P_g - r^B_g)}_{\text{交差項}}$$

- 配分効果が**ベンチマーク全体に対する相対リターン $r^B_g - r^B$** に掛かる。「平均より良いグループをオーバーウェイトしたか」という自然な問いに対応。$\sum_g (w^P_g - w^B_g) = 0$ より $r^B$ の項は全体では消えるため、**トータルはBHBと一致**し、グループ別の配分効果の見え方だけが変わる
- 実務レポートのデファクトスタンダード

#### (3) 2項分解（交差項を選択に吸収）

交差項は解釈が難しく報告先に説明しづらいため、選択効果に畳み込む版が広く使われる:

$$r^A = \underbrace{\sum_g (w^P_g - w^B_g)(r^B_g - r^B)}_{\text{配分（BF型）}} + \underbrace{\sum_g w^P_g \, (r^P_g - r^B_g)}_{\text{選択（ポートフォリオウェイト版）}}$$

- 選択効果のウェイトが $w^B_g$ から $w^P_g$ に変わることで交差項が選択側に吸収される（恒等変形: $w^B_g(r^P_g - r^B_g) + (w^P_g - w^B_g)(r^P_g - r^B_g) = w^P_g(r^P_g - r^B_g)$）
- 逆に交差項を配分側に吸収する版（配分のウェイト差に $r^P_g$ を掛ける）もあるが少数派

#### バージョン選択の指針

| 観点 | 推奨 |
|---|---|
| 社内診断・意思決定プロセスとの対応 | 配分判断と銘柄選択が組織的に分業されているなら3項（交差項を明示） |
| 対外報告・簡明さ | 2項（BF配分 + $w^P$ 選択）が最も説明しやすい |
| 共通ルール | どの版でも**トータルは同一**（分解の内訳が違うだけ）。使用バージョンと交差項の帰属規約をレポートに明記し、期間を通じて変えない |

- いずれの版も、ウェイトは期初・リターンは期中という第0章の大原則に従う
- クオンツ戦略の診断にはファクターベース分解のほうが情報量が多いが、Brinson型は非クオンツの関係者への報告で共通言語になる

### 多期間の集計

単期間の分解は加法的だが、多期間では複利効果で単純合計とトータルが一致しない。実務では**リンキング係数**（Cariño法等）で調整して累積寄与を報告する。規約を決めて一貫して使う。

## 7.4 評価段階のバイアス（再掲と追加）

| バイアス | 内容 | 対処 |
|---|---|---|
| 選択バイアス | 多数の戦略バリエーションから事後的に最良を報告 | 試行数の記録、デフレートSR等の多重検定調整、ホールドアウト期間 |
| バックフィル | 戦略開始前の「シミュレーション期間」と実運用期間の接続 | 期間を明示的に区分して報告 |
| 評価期間の恣意性 | 開始・終了時点の選び方で成績が大きく変わる | 全期間＋サブ期間（レジーム別）を併記 |
| 分位分析と実装の乖離 | 分位L/Sスプレッドはコスト・制約なしの理想値 | 第6章の制約付き最適化・コスト込みバックテスト（第8章）で確認 |

## 7.5 チェックリスト

1. 分位割当は期初スコア・リターンは期中、の非重複が守られているか
2. 等ウェイトと時価総額ウェイトの両方で分位分析を行ったか（小型株効果の切り分け）
3. カントリー/業種中立の方式（グループ内分位 or 中立化スコア）がIC評価と整合しているか
4. アトリビューションのエクスポージャーは期初値か
5. グロス/ネット、全期間/サブ期間を併記したか
6. 実現TEと予測TEの乖離を監視しているか
