# 第2章: ファクター定義とスコアリング

生データ（raw descriptor）から、モデルで使えるエクスポージャー $x_{i,k,t}$ に変換するまでの処理を整理する。処理は毎期 $t$ ごとに、**その時点のクロスセクションで独立に**行うのが基本形。

処理パイプライン:

$$\text{raw } d_{i,k,t} \;\to\; \text{欠損処理} \;\to\; \text{外れ値処理} \;\to\; \text{標準化} \;\to\; \text{中立化} \;\to\; x_{i,k,t}$$

## 2.1 代表的ファクターの定義とデータ時点

各定義の分子・分母で「いつの値か」を明示する。$t$ はリバランス時点、$\text{ann}(\cdot) \le t$ は「発表日が $t$ 以前の最新値」を表す。

| ファクター | 定義例 | 分子の時点 | 分母の時点 |
|---|---|---|---|
| バリュー (B/P) | $\dfrac{\text{BookValue}^{\text{ann} \le t}_i}{\text{MktCap}_{i,t}}$ | 発表済み最新の純資産 | **$t$ 時点**の時価総額 |
| 益回り (E/P) | $\dfrac{\text{Earnings}^{\text{ann} \le t}_{i,\text{TTM}}}{\text{MktCap}_{i,t}}$ | 発表済み直近12ヶ月利益 | 同上 |
| モメンタム | $\dfrac{P_{i,t-1\text{M}}}{P_{i,t-12\text{M}}} - 1$ | — | — |
| 低ボラ | $-\hat{\sigma}_i\big(r_{i,s},\ s \in [t-L, t]\big)$ | 過去 $L$ 日の日次リターン | — |
| クオリティ (ROE) | $\dfrac{\text{Earnings}^{\text{ann} \le t}_{i,\text{TTM}}}{\text{BookValue}^{\text{ann} \le t}_i}$ | 発表済み | 発表済み |
| サイズ | $-\log \text{MktCap}_{i,t}$ | $t$ 時点 | — |

タイミング上の注意:

- **会計値と市場値の混合**（B/P等）: 分母の時価総額は $t$ 時点の最新値でよい（市場価格は常に観測可能）。分子だけ発表日ルールに従う。「決算期末の時価総額」を使う流儀もあるが、規約として固定し全ファクターで統一する。
- **モメンタムの直近1ヶ月除外**: $t-12\text{M} \to t-1\text{M}$ が標準（直近1ヶ月は短期リバーサルと相殺するため除外）。これはルックアヘッドではなく設計判断。
- **TTM（直近12ヶ月）合成**: 四半期発表値を発表日ベースで繋ぐ。年度値しか取れない場合はその開示ラグに従う。

## 2.2 欠損値処理

時点 $t$ で $d_{i,k,t}$ が欠損の場合の選択肢:

1. **除外**: ファクター $k$ のスコアリング対象から外す（最終合成時に利用可能ファクターのみで再ウェイト）
2. **中央値代入**: セクター内中央値等（クロスセクション、時点 $t$ の値のみで計算）
3. **直近値の繰越（LOCF）**: 有効期限を設ける（例: 財務データは発表から15ヶ月で失効）

注意:

- 代入値の計算に**将来時点や全期間の統計を使わない**（時点 $t$ のクロスセクション統計のみ）
- 欠損が**情報を持つ**場合がある（開示しない企業＝ガバナンス低位、等）。機械的代入の前に欠損メカニズムを確認
- 欠損率が高いファクターはユニバースの偏り（大型株のみカバー等）を通じて暗黙のサイズ・ティルトを生む

## 2.3 外れ値処理（ウィンザライズ）

時点 $t$ のクロスセクション分位点でクリップ:

$$d^{w}_{i,k,t} = \min\big( \max(d_{i,k,t},\ q^{(p)}_{k,t}),\ q^{(1-p)}_{k,t} \big), \qquad p = 0.01 \sim 0.05$$

または中央値絶対偏差（MAD）ベース:

$$d^{w}_{i,k,t} = \text{clip}\big(d_{i,k,t};\ \text{med}_{k,t} \pm c \cdot \text{MAD}_{k,t}\big), \qquad c = 3 \sim 5$$

- 分位点・MADはいずれも**時点 $t$ のクロスセクション**で計算（全期間プールは不可 — 分布の水準シフトで将来情報が混入する）
- 比率系ファクター（E/P等）は分母が小さい銘柄で発散しやすい。ウィンザライズの前に**分母の符号・ゼロ近傍の扱い**（赤字企業のE/P等）を規約化する

## 2.4 標準化

### クロスセクションz-score（基本形）

$$z_{i,k,t} = \frac{d^w_{i,k,t} - \mu_{k,t}}{\sigma_{k,t}}, \qquad \mu_{k,t}, \sigma_{k,t}: \text{時点 } t \text{ のクロスセクション統計}$$

- $\mu_{k,t}$ に**等ウェイト平均か時価総額ウェイト平均か**を選択（Barra流は「ユニバースの時価総額加重平均でゼロ」＝ベンチマークのエクスポージャーが概ねゼロになるよう規準化）。$\sigma_{k,t}$ は等ウェイトが一般的。
- 標準化後に再度 $|z| \le 3$ 等でクリップする実務も多い。

### ランク変換（頑健な代替）

$$z^{\text{rank}}_{i,k,t} = \Phi^{-1}\left( \frac{\text{rank}(d_{i,k,t}) - 0.5}{N_t} \right)$$

外れ値に頑健で分布形状を固定できる。情報の一部（距離）を捨てるトレードオフ。

### 時系列標準化を使う場合のPIT規律

ファクターによっては自銘柄の時系列で標準化したい場合がある（例: 銘柄固有の売買回転率の異常度）。その場合:

$$z_{i,k,t} = \frac{d_{i,k,t} - \hat{\mu}_{i,k}(t' \le t)}{\hat{\sigma}_{i,k}(t' \le t)}$$

**平均・分散は時点 $t$ までのexpanding/rollingウィンドウのみ**。全期間統計での標準化はバックテストで最も混入しやすいルックアヘッドの一つ（「その銘柄にとって高い水準か」を将来を含めて判定してしまう）。

## 2.5 中立化（ニュートラライズ）

ファクター $k$ から不要なエクスポージャー（業種・国・サイズ等）を除去する。時点 $t$ のクロスセクション回帰の残差を取る:

$$z_{i,k,t} = \gamma_0 + \sum_{g} \gamma_g \, \mathbb{1}[i \in g] + \gamma_s \, \text{Size}_{i,t} + \varepsilon_{i,k,t}, \qquad x_{i,k,t} \equiv \frac{\varepsilon_{i,k,t}}{\sigma(\varepsilon_{\cdot,k,t})}$$

- $\mathbb{1}[i \in g]$: 業種（・国）ダミー。**業種分類も時点 $t$ 当時の分類**を使う（GICS等の分類変更・企業の業種変更は遡及されがち）
- 簡便法: 業種内でのdemean（$z_{i,k,t} - \bar{z}_{g(i),k,t}$）。回帰版はサイズ等の連続変数も同時に落とせる点で優る
- **何に対して中立化するかは戦略仕様**: 業種内選別戦略なら業種中立化は必須。業種配分もアルファ源とするなら中立化しない。第5章のリスクモデルとの整合（アルファとリスクファクターの直交性）は第4章で扱う

## 2.6 合成スコア

複数ファクターの合成:

$$s_{i,t} = \sum_k v_{k,t} \, x_{i,k,t}, \qquad \sum_k |v_{k,t}| = 1 \ \text{等の規準化}$$

- 等ウェイト（$v_{k,t} = 1/K$）が頑健なベースライン
- $v_{k,t}$ を過去のファクター実績（IC等）で動的に決める場合、**$v_{k,t}$ の推定に使うのは時点 $t$ までの実績のみ**。バックテスト全期間のICで固定ウェイトを決めるのは典型的なインサンプル最適化（ルックアヘッド）
- 合成後に再標準化（クロスセクションz-score）してからポートフォリオ構築へ渡す

## 2.7 チェックリスト

1. 各ファクターの分子・分母それぞれについて「発表日 $\le t$」を確認したか
2. ウィンザライズ・標準化・欠損代入の統計量はすべて**時点 $t$ のクロスセクション**（または $t$ までの時系列）か
3. 時系列標準化・動的ファクターウェイトに全期間統計を使っていないか
4. 業種分類は時点 $t$ 当時のものか
5. 欠損の発生パターンがユニバースの偏り（サイズ等）を生んでいないか
6. 赤字企業・分母ゼロ近傍の処理規約は明文化されているか
