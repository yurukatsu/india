# Agnostic Fundamental Analysis（Bartram–Grinblatt 2018 の模倣）

`scripts/build_agnostic.py` で `core` から生成。各月、ユニバースの非金融銘柄の時価総額 V を財務項目の水準に横断面回帰して公正価値 P を推定し、乖離率 M = (P − V) / V を Blom 化したもの。**高いほど割安**。金融セクター（GICS 40）はスコアなし。

## スコア

R² は水準の決定係数、順位相関は P と V の Spearman、P ≤ 0 は公正価値が 0 以下になった銘柄の割合（いずれも月次の中央値・平均。月別は `fit_stats.csv`）。

| スコア | モデル | R² 中央値 | 順位相関 中央値 | P ≤ 0 | 期間 |
| --- | --- | --- | --- | --- | --- |
| `afa_ols_is` | OLS（定数項あり）。学習に使った銘柄そのものを予測（論文どおりの in-sample 公正価値） | 0.868 | 0.617 | 5.0% | 200801〜202607 |
| `afa_ts` | 論文の Theil–Sen 型。無作為 100 銘柄の OLS で全銘柄を予測、を 1 万回繰り返し、銘柄ごとの予測値の中央値を公正価値とする（論文は 10 万回。学習に使った銘柄も予測する in-sample） | 0.872 | 0.701 | 3.6% | 200801〜202607 |
| `afa_ols` | OLS（定数項あり）。K 分割の交差推定 | 0.302 | 0.559 | 6.4% | 200801〜202607 |
| `afa_ridge` | Ridge。特徴量を学習データで標準化し、α は LOO（RidgeCV、10^-4〜10^4）で選ぶ。K 分割の交差推定 | 0.516 | 0.654 | 2.1% | 200801〜202607 |
| `afa_lasso` | Lasso。特徴量を学習データで標準化し、α は内側 5 分割 CV（LassoCV）で選ぶ。K 分割の交差推定 | 0.549 | 0.635 | 1.4% | 200801〜202607 |
| `afa_rf` | Random Forest（500 本、葉の最小 3 銘柄、分割候補 1/3）。log 時価総額を log 総資産 + 総資産比の比率で予測。K 分割の交差推定 | 0.274 | 0.709 | 0.0% | 200801〜202607 |
| `afa_lgbm` | LightGBM（300 回、学習率 0.05、葉 15、葉の最小 10 銘柄、行・列 80% サンプリング、L2 1.0）。log 時価総額を log 総資産 + 総資産比の比率で予測。K 分割の交差推定 | 0.445 | 0.722 | 0.0% | 200801〜202607 |

## 財務項目

総資産 TA = TL / `tl_ta`、負債 TL = `mv` / `mve_tl`。ほかは下表。各項目を総資産で割った比率を、その月までの全履歴（2003 年以降のユニバースの非金融銘柄）の 5% / 95% 点で winsorize してから TA を掛け戻す。線形モデルは水準（TA, TL と下表）、木系は log TA と各項目 / TA の比率を特徴量にする。

| 項目 | 内容 | 復元式 |
| --- | --- | --- |
| `be` | 簿価（株主資本） | `bp_act` × MV |
| `ni` | 純利益 | `ep_act` × MV |
| `sales` | 売上高 | `sp_act` × MV |
| `cfe` | キャッシュ利益 | `cfp_act` × MV |
| `ocf` | 営業 CF | `ocfp` × MV |
| `div` | 配当 | `dp_act` × MV |
| `td` | 有利子負債 | `td_ta` × TA |
| `re` | 利益剰余金 | `re_ta` × TA |
| `wk` | 運転資本 | `wk_ta` × TA |
| `ebit` | EBIT | `ebit_ta` × TA |
| `gp` | 売上総利益 | `gpa_act` × TA |
| `sga` | 販管費 | `sga_ta` × TA |
| `pti` | 税引前利益 | `pti_tl` × TL |

## 論文との違い

- 財務データは `core` の `*_act`（年次決算。3 月期決算の発表後、主に 5〜7 月に更新）。論文は四半期の直近 12 か月と直近四半期末の残高（Compustat PIT）、28 項目。
- `sales_ta` は 2013〜2020 年に一部銘柄で壊れている（為替レート分ずれる）ため使わず、売上は `sp_act × mv`。
- FCF（`fcfp`）は 2019 年 4〜8 月に最大 85% の銘柄で欠損するため使わない（営業 CF は使う）。
- 交差推定（K 分割）は論文に無い。論文と同じ in-sample の推定は `afa_ols_is`。
- 木系は論文に無い（Geertsema–Lu 2023 型の拡張）。
