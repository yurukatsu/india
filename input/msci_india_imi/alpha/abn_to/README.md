# 異常回転率（abnormal turnover）

`scripts/build_abn_to.py` で `data/turnover` の日次回転率（売買株数 / 発行済株数）から生成。月末 t までのデータだけを使い、各月ユニバースの構成銘柄に絞った素の値（高いほど出来高が平常より多い）。検証は `experiments/abn_to/`。

| スコア | 定義 | 期間 | カバレッジ |
| --- | --- | --- | --- |
| `abn_to` | log(当月の日次回転率の平均 / 過去 12 か月の月平均の平均)。本命 | 200307〜202607 | 0.989 |
| `abn_to_med` | log(当月の日次回転率の中央値 / 前月末までの 252 営業日の中央値)。ブロック取引に頑健 | 200307〜202607 | 0.989 |
| `abn_to_q` | log(直近 3 か月の平均 / その前の 12 か月の平均)。遅い版 | 200309〜202607 | 0.985 |
