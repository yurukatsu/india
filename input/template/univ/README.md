# univ

ユニバースのデータフォーマットについて整理します。

## 1. ファイルフォーマット

- ファイル形式：`dat`
- gzip圧縮：可能（例：`.dat.gz`）
- 区切り文字：
  - `dat`ファイル：半角スペース（` `）

## 2. データ形式

| 項目名 | 説明 |
|---|---|
| `code` | 対象銘柄の取引コードを指定。今回は `bid`（BARRA ID）を指定 |
| `weight` | 対象銘柄コードに対する保有割合（本来は銘柄コードだけわかればいいが、対象のインデックス等があればインデックスウェイトを載せておく。なければ、等ウェイトなど適当な値で良い） |

## 3. ヘッダー情報

ファイル先頭に`#`で始まる設定情報を記載できる。

| 設定項目 | 説明 |
|---|---|
| `format` | データ形式。サンプルでは`weight`を指定 |
| `date` | 基準日 |

## 4. 入力サンプル

ファイル名が `20230331.dat` の場合

```text
# format = weight
# date = 20230331
KORACL1 1.18483412322275E-03
HKGCYF1 1.18483412322275E-03
BRAAAP1 1.18483412322275E-03
HKGDAR1 1.18483412322275E-03
```

ファイル名が `202303.dat` の場合

```text
# format = weight
# date = 202303
KORACL1 1.18483412322275E-03
HKGCYF1 1.18483412322275E-03
BRAAAP1 1.18483412322275E-03
HKGDAR1 1.18483412322275E-03
```

## 4. ユニバースデータの格納方法

基準日ごとにファイルを作成。
ファイル名は `YYYYMM.dat` または `YYYYMMDD.dat` にすること。

```text
.
└── yyyymm.dat
```

## 6. 注意事項

- `code`には該当株の取引コードを指定する。欠損なし。
- `weight`には該当銘柄の保有割合を指定する。欠損なし。
- `format`には使用するデータ形式を指定する。
- `date`にはユニバースの基準日を`YYYYMMDD`形式で指定する。
- `#`で始まる行はコメントまたはヘッダー情報として扱う。
- `weight`には指数表記を使用できる。
- ファイルはgzip形式で圧縮してもよい。
