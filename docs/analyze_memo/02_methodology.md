# 2. 手法と実装規約

実装はすべて `src/factorlab/`。ファクター名を差し替えるだけで再実行できる。

| モジュール | 役割 |
|---|---|
| `data` | パネル構築・先行リターン付与・カバレッジ |
| `preprocess` | winsorize / z-score / **Blom** / 中立化（回帰残差） |
| `quantile` | 分位分割・分位リターン・回転率・サマリ |
| `ic` | 月次 IC・要約・減衰（h=1..12） |
| `regression` | クロスセクション回帰によるファクターリターン f_t |
| `multi` | 100本一括スキャン・相関/重複行列・スタイル合成 |
| `altdata` | alt/AI ローダー・スコア特性 |
| `plotting` | 全図（図中テキストは英語） |

## 2.1 前処理（毎月クロスセクションで完結、PIT）

- **Blom 正規スコア**（既定）: 順位 r、有効数 n に対し `z = Φ⁻¹((r − 3/8)/(n + 1/4))`。
  同順位は平均順位。裾の厚い分布でも標準正規形に固定される
- z-score 版は winsorize(片側1%) → 標準化
- **Spearman IC は単調変換で不変**なので raw/z/Blom で同一（検証済み）。前処理の選択が効くのは分位分析と回帰

## 2.2 分位分析（`quantile_returns`）

- 一様順位 `u = (r − 0.5)/n` を [0,1] の等分割で切る。**昇順・降順で厳密に鏡像**
  （`ceil(rank·q/n)` 方式は n が q で割り切れない月に非対称 → 不採用）
- **Q5 = スコア最上位**、ロングショートは Q5−Q1
- EW: 分位内等ウェイト vs ベンチ等ウェイト / CW: 時価総額ウェイト vs ベンチ時価総額ウェイト
- 表示は**幾何年率の超過リターン**、時系列は**累積超過リターン**（ユーザー指定）。
  幾何にはボラティリティ・ドラッグが乗る点に注意（算術 `ann_excess_arith` も表に併記）
- **回転率**: 期中ドリフト調整済み片道回転率。ランダムスコアで理論値 1−1/q = 0.80 に一致することを検証
- DD は2種: `max_dd`（分位ポート自体）と `max_dd_excess`（累積超過系列 = 対ベンチの劣後幅）
- t 値は Newey-West（月次超過の算術平均に対する検定。幾何バーと符号がズレ得る）

## 2.3 IC

- 月次クロスセクション Spearman（既定）。要約: 平均 IC・ICIR（×√12）・NW t・勝率・1次自己相関
- 減衰は h ヶ月先の**単月**リターンに対する IC（h=1..12、区間重複なし）

## 2.4 ファクターリターン（`regression.factor_return`）

毎月 `r_{i,t→t+1} = a_t + f_t·x_{i,t} + u_{i,t}` を推定。
標準化スコアなら f_t は「1SD エクスポージャーあたりの月次リターン」で、
**f_t ≈ IC^Pearson_t × σ_t(r)** が成立（実測 corr 0.9997）。

- ウェイト: `ew` / `sqrt_cap`（Barra流）/ `cap`
- 累積は単純和を主・複利を従（ゼロ投資ポートなので）
- IR = f̄/σ_f はシャープレシオ相当として有効。**DD の水準は実装 P&L の予測には使えない**
  （ウェイト無制約・コストゼロ・グロス変動。分位 L/S の DD は約2倍深い）

## 2.5 中立化（size + sector）

Blom スコアを目的変数に、**GICS 上2桁の11セクターダミー + log_cap** への
クロスセクション回帰（毎月・1本の回帰で同時）を行い、残差を SD=1 に再スケール。

- 計画行列はダミー全部+定数で設計上共線だが、lstsq の最小ノルム解の**残差は
  ダミー1本落としの教科書型と厳密一致**（検証済み、max diff 7e-14）
- 診断: corr(score, log_cap) = 0、セクター平均スコアの分散 = 0 を確認
- 逐次（サイズ→セクター）ではなく同時に落とす（順序依存の回避）

## 2.6 多ファクター比較（`multi`）

- **スコアボード**: 1行1ファクターで Q5−Q1 / Q5 の超過・IR・NW t・DD・回転率・IC
- **相関行列**: 月次クロスセクション Spearman の期間平均。高速化のため
  「列ごとに1回ランク→ペアワイズ内積」。完全ケースで pandas と厳密一致、
  欠損ペアでは最大 0.02 程度の差（ペアごと再ランクとの流儀差）
- **Q5 重複率**: `|Q5^a ∩ Q5^b| / √(|Q5^a||Q5^b|)`。無相関で 1/q = 0.20（検証済み）
- 見せ方の分担: **パフォーマンス = 縦棒チャート**（スタイル色分け、* = NW |t|≥2）、
  **類似度 = 相関のみのヒートマップ**（core.yaml のスタイル階層を色帯+区切り線で表示）
