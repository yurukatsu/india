## 3.1 個別深掘り（Step 1〜4）

### B/P（bp_act）— 効かない

- 分位は非単調（Q2 が最良 +1.4%、Q5 = 極端割安が最悪 −3.2%）。バリュートラップ型
- IC −0.017（NW t = −1.3）、減衰はフラット、全ホライズン非有意
- 累積 IC は 2012 年まで上昇 → 2020 年まで一貫下落 → 足元やや回復の完全なレジーム反転
- 中立化でも救われない（sector 単独ではむしろ逆張り側に悪化 t = −1.7）
- ファクターリターンも全バリアントでゼロ近傍（f = 0.01〜0.08%/月）
